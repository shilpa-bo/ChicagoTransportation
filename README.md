# Overview 
This project analyzes and models transportation networks in Chicago using data from the TransportationNetworks repository. 
The goal of this project is to propose a framework for transit expansion using various methods of network analysis. To learn more look at `presentation_report.pdf`.
The datasets provide road network structures, traffic flow data, and other transportation-related information. Learn more about the repo at (https://github.com/bstabler/TransportationNetworks/tree/master/Chicago-Sketch)
The repository contains various scripts for preprocessing, analyzing, and visualizing the data.

# Files Information: 
* `base_network_analysis.ipynb`: simple network analysis (mean degree, strongly/weakly connected components, etc.) 
* `map_overlay.ipynb`: Experimenting with different centralitites and plotting
* `od_analysis.ipynb`: Origin Destination demand analysis. Computes highest cost pairs, simulates new links based on these pairs as a idealized metro system
* `resilience_analysis.ipynb`: Network Resilience Analysis

The report is under the file: Chicago_Transportation_Analysis.pdf
